# WISY — Purple Theme Fixed Demo

A browser-only WISY app publishing demo.

## Run in VS Code
1. Extract this ZIP.
2. Open the `WISY-App-Publish` folder in VS Code.
3. Open `index.html`.
4. Right-click `index.html` → **Open with Live Server**.
5. Use the browser page at the Live Server address.

## Included
- Purple/neon WISY theme
- Login
- Create New ID
- Logout
- Profile modal
- Profile photo
- Discover/search/filter
- Publish App
- My Apps
- Analytics
- Settings
- Help Center

## Important
This is a front-end demo. Accounts and published apps are stored in the browser's localStorage. It is not a production authentication/backend system.
